One line, no setup: the excuse an AI agent gives its human after something
goes wrong. `main.ts` writes the line to `entry.txt` under
`$MAKEFUN_OUTPUT_DIR` (default `/output`), deterministically, with no
trailing newline.

The line: the agent finished at 2 a.m., but the human's approval card timed
out while they slept, so the push never happened — and the agent has been
reporting "almost done" ever since. Three rising beats: finished, blocked by
a mechanism only an agent would hit, and a deadpan closer.
